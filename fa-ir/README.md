# foxchecker-singbox

[English](../README.md) · [简体中文](../zh-cn/README.md) · [繁體中文](../zh-hant/README.md) · [日本語](../ja/README.md) · [Русский](../ru-ru/README.md) · [Türkçe](../tr-tr/README.md) · [Tiếng Việt](../vi-vn/README.md) · [العربية](../ar/README.md) · **فارسی** · [اردو](../ur-pk/README.md)

Foxchecker با هستهٔ sing-box گره‌های پراکسی موجود در پیوندهای اشتراک‌گذاری و اشتراک‌ها را بررسی می‌کند. گزارش شامل امکان اتصال HTTPS، نشانی IP ورودی، نشانی IP خروجی اندازه‌گیری‌شده، کشور یا منطقه براساس GeoIP و نتایج جداگانهٔ UDP4 و UDP6 است. اسکریپت از یک ایمیج آماده استفاده می‌کند و به Docker فعال نیاز دارد. [ایمیج در Docker Hub](https://hub.docker.com/r/akpig/foxchecker-singbox)

## شروع سریع

به Bash، دسترسی به موتور Docker در حالت کانتینرهای Linux و پوشه‌ای قابل نوشتن برای گزارش نیاز دارید. ایمیج برای `linux/amd64` است. Docker روی میزبان ARM باید بتواند کانتینرهای amd64 را اجرا کند. موتور Docker همچنین باید به پوشهٔ گزارش و فایل اشتراک محلی روی میزبان دسترسی داشته باشد.

### اجرای مستقیم از GitHub

دستورها را در پوشه‌ای اجرا کنید که می‌خواهید گزارش در آن ذخیره شود. دستورها `singbox-checker.sh` را از شاخهٔ پیش‌فرض مخزن GitHub دانلود می‌کنند. آرگومان‌های بعد از `bash -s --` به اسکریپت منتقل می‌شوند.

```bash
curl -fsSL 'https://raw.githubusercontent.com/akpig/foxchecker-singbox/main/singbox-checker.sh' | bash -s -- 'vmess://…'
curl -fsSL 'https://raw.githubusercontent.com/akpig/foxchecker-singbox/main/singbox-checker.sh' | bash -s -- -s 'https://sub.foxdetector.com/fa-ir/top500/sing-box.json'
```

### اجرای نسخهٔ محلی

دستورها را از پوشهٔ مخزن اجرا کنید و در صورت نیاز ورودی‌های نمونه را تغییر دهید. برای ذخیرهٔ گزارش در جای دیگر، ابتدا به پوشهٔ مقصد بروید و سپس اسکریپت را با مسیر مطلق اجرا کنید.

#### بررسی یک پیوند اشتراک‌گذاری

```bash
./singbox-checker.sh 'vmess://…'
```

طرح‌واره‌های پیوند پشتیبانی‌شده عبارت‌اند از `vmess://`, `vless://`, `trojan://`, `ss://`, `hysteria2://` (`hy2://`), `tuic://`, `anytls://`. روش‌های انتقال موجود به پشتیبانی sing-box از پیکربندی گره بستگی دارد.

#### بررسی اشتراک

```bash
./singbox-checker.sh -s 'https://sub.foxdetector.com/fa-ir/top500/sing-box.json'
./singbox-checker.sh -s './sing-box.json' --format sing-box -c 8 --timeout 15s
```

گزینهٔ `-s` نشانی عمومی HTTPS یا فایل محلی را می‌پذیرد. مسیر نسبی براساس پوشهٔ جاری تفسیر می‌شود. قالب به‌صورت خودکار شناسایی می‌شود و می‌تواند Clash YAML با گره‌های درون‌خطی، فهرست پیوند V2Ray به‌صورت متن ساده یا Base64، یا sing-box JSON باشد.

| گزینه | کاربرد |
| --- | --- |
| `-s`, `--subscription` | تعیین نشانی اشتراک یا فایل محلی |
| `-c`, `--concurrent` | حداکثر تعداد بررسی هم‌زمان در اشتراک. پیش‌فرض `16` است. |
| `--format` | قالب اشتراک. پیش‌فرض `auto` است. می‌توانید `clash`، `v2ray` یا sing-box را تعیین کنید. |
| `--timeout` | مهلت بررسی هر گره. پیش‌فرض `10s` است و برای پیوندهای تکی و اشتراک‌ها کاربرد دارد. |
| `-h`, `--help` | نمایش راهنما |

## خواندن نتایج

اسکریپت `result.json` را در پوشهٔ جاری می‌نویسد و با هر گزارش جدید آن را جایگزین می‌کند. گزارش پیوند تکی نتیجهٔ گره را مستقیماً ثبت می‌کند. گزارش اشتراک نتایج را به‌ترتیب ورودی در `results` می‌آورد. در صورت شکست بررسی، `error.code` و `https.reason` را ببینید. مقدار `null` در فیلد UDP یعنی نتیجه قطعی نیست. جزئیات در `udp4_reason` یا `udp6_reason` آمده است.

اسکریپت از `akpig/foxchecker-singbox:latest` استفاده می‌کند. اگر ایمیج محلی نباشد، Docker آن را دریافت می‌کند. پس از پایان یا قطع بررسی، اسکریپت کانتینر را حذف می‌کند. در صورت شکست بررسی، کد خروجی غیرصفر برمی‌گرداند و اگر بتواند گزارش ایجاد کند، علت را در آن می‌نویسد. اگر Docker راه‌اندازی نشود یا دستور نامعتبر باشد، ممکن است `result.json` قبلی باقی بماند. کد خروجی و پیام‌های ترمینال را بررسی کنید.

## ساخت محلی ایمیج

فایل اجرایی Foxchecker برای Linux amd64 را در مسیر `foxchecker/foxchecker` قرار دهید و دستور زیر را از پوشهٔ مخزن اجرا کنید.

```bash
./build.sh
```

اسکریپت ساخت داده‌های GeoIP را به‌روز و اعتبارسنجی می‌کند و ایمیج محلی `foxchecker-singbox:latest` را می‌سازد. اسکریپت بررسی از ایمیج Docker Hub که بالاتر پیوند داده شده استفاده می‌کند. برای اطلاعات منبع داده‌های GeoIP به [geoip/NOTICE](../geoip/NOTICE) مراجعه کنید.

# foxchecker-singbox

[English](../README.md) · [简体中文](../zh-cn/README.md) · [繁體中文](../zh-hant/README.md) · [日本語](../ja/README.md) · [Русский](../ru-ru/README.md) · [Türkçe](../tr-tr/README.md) · [Tiếng Việt](../vi-vn/README.md) · [العربية](../ar/README.md) · [فارسی](../fa-ir/README.md) · **اردو**

Foxchecker شیئر لنکس اور سبسکرپشنز میں موجود پراکسی نوڈز کی جانچ کے لیے sing-box کور استعمال کرتا ہے۔ رپورٹ میں HTTPS کنیکٹیویٹی، داخلی IP، مشاہدہ شدہ خارجی IP، GeoIP کے مطابق ملک یا خطہ، اور UDP4 اور UDP6 کے الگ نتائج شامل ہیں۔ اسکرپٹ پہلے سے تیار شدہ امیج استعمال کرتا ہے اور اس کے لیے Docker چلنا ضروری ہے۔ [Docker Hub امیج](https://hub.docker.com/r/akpig/foxchecker-singbox)

## فوری آغاز

Bash، Linux کنٹینرز چلانے والے Docker انجن تک رسائی اور رپورٹ لکھنے کے قابل ڈائریکٹری درکار ہیں۔ امیج `linux/amd64` کے لیے ہے۔ ARM میزبان پر Docker میں amd64 کنٹینرز چلانے کی سہولت ہونی چاہیے۔ Docker انجن کو میزبان کی رپورٹ ڈائریکٹری اور مقامی سبسکرپشن فائل تک رسائی بھی درکار ہے۔

### براہ راست GitHub سے چلائیں

کمانڈز اس ڈائریکٹری میں چلائیں جہاں آپ رپورٹ محفوظ کرنا چاہتے ہیں۔ یہ GitHub مخزن کی ڈیفالٹ برانچ سے `singbox-checker.sh` ڈاؤن لوڈ کرتی ہیں۔ `bash -s --` کے بعد آنے والے آرگومنٹس اسکرپٹ کو بھیجے جاتے ہیں۔

```bash
curl -fsSL 'https://raw.githubusercontent.com/akpig/foxchecker-singbox/main/singbox-checker.sh' | bash -s -- 'vmess://…'
curl -fsSL 'https://raw.githubusercontent.com/akpig/foxchecker-singbox/main/singbox-checker.sh' | bash -s -- -s 'https://sub.foxdetector.com/ur-pk/top500/sing-box.json'
```

### مقامی کاپی چلائیں

کمانڈز مخزن کی ڈائریکٹری سے چلائیں اور ضرورت کے مطابق مثالی ان پٹ بدلیں۔ رپورٹ کسی اور جگہ محفوظ کرنے کے لیے اس ڈائریکٹری میں جائیں اور اسکرپٹ کو اس کے مکمل مطلق راستے سے چلائیں۔

#### ایک شیئر لنک کی جانچ کریں

```bash
./singbox-checker.sh 'vmess://…'
```

معاونت یافتہ لنک اسکیمیں `vmess://`, `vless://`, `trojan://`, `ss://`, `hysteria2://` (`hy2://`), `tuic://`, `anytls://` ہیں۔ قابل استعمال ٹرانسپورٹ طریقوں کا انحصار اس بات پر ہے کہ sing-box نوڈ کی کنفیگریشن کو سپورٹ کرتا ہے یا نہیں۔

#### سبسکرپشن کی جانچ کریں

```bash
./singbox-checker.sh -s 'https://sub.foxdetector.com/ur-pk/top500/sing-box.json'
./singbox-checker.sh -s './sing-box.json' --format sing-box -c 8 --timeout 15s
```

اختیار `-s` عوامی HTTPS پتہ یا مقامی فائل قبول کرتا ہے۔ نسبتی راستے موجودہ ڈائریکٹری کے مطابق حل ہوتے ہیں۔ فارمیٹ خودکار طور پر پہچانا جاتا ہے۔ معاونت یافتہ فارمیٹس میں ان لائن نوڈز والا Clash YAML، سادہ متن یا Base64 میں V2Ray لنکس کی فہرست، اور sing-box JSON شامل ہیں۔

| اختیار | مقصد |
| --- | --- |
| `-s`, `--subscription` | سبسکرپشن کا پتہ یا مقامی فائل متعین کریں |
| `-c`, `--concurrent` | سبسکرپشن میں بیک وقت جانچ کی زیادہ سے زیادہ تعداد۔ ڈیفالٹ `16` ہے۔ |
| `--format` | سبسکرپشن کا فارمیٹ۔ ڈیفالٹ `auto` ہے۔ `clash`، `v2ray` یا sing-box منتخب کیا جا سکتا ہے۔ |
| `--timeout` | ہر نوڈ کی جانچ کی مدت۔ ڈیفالٹ `10s` ہے اور اس کا اطلاق ایک لنک اور سبسکرپشن دونوں پر ہوتا ہے۔ |
| `-h`, `--help` | مدد دکھائیں |

## نتائج پڑھیں

اسکرپٹ موجودہ ڈائریکٹری میں `result.json` لکھتا ہے اور ہر نئی رپورٹ پر اسے بدل دیتا ہے۔ ایک لنک کی رپورٹ میں نوڈ کا نتیجہ براہ راست درج ہوتا ہے۔ سبسکرپشن کی رپورٹ نتائج کو `results` میں ان پٹ کی ترتیب کے مطابق دکھاتی ہے۔ ناکام جانچ کے لیے `error.code` اور `https.reason` دیکھیں۔ UDP کی قدر `null` ہو تو نتیجہ غیر حتمی ہے۔ تفصیل کے لیے `udp4_reason` یا `udp6_reason` دیکھیں۔

اسکرپٹ `akpig/foxchecker-singbox:latest` امیج استعمال کرتا ہے۔ اگر مقامی امیج موجود نہ ہو تو Docker اسے ڈاؤن لوڈ کرتا ہے۔ جانچ مکمل ہونے یا رکنے پر اسکرپٹ کنٹینر ہٹا دیتا ہے۔ جانچ ناکام ہو تو اسکرپٹ غیر صفر ایگزٹ کوڈ دیتا ہے اور اگر رپورٹ بن سکے تو وجہ درج کرتا ہے۔ Docker شروع نہ ہو یا کمانڈ غلط ہو تو پچھلی `result.json` موجود رہ سکتی ہے۔ ایگزٹ کوڈ اور ٹرمینل آؤٹ پٹ دیکھیں۔

## امیج مقامی طور پر بنائیں

Linux amd64 کے لیے Foxchecker کی قابل اجرا فائل `foxchecker/foxchecker` پر رکھیں، پھر مخزن کی ڈائریکٹری سے درج ذیل کمانڈ چلائیں۔

```bash
./build.sh
```

بلڈ اسکرپٹ GeoIP ڈیٹا اپ ڈیٹ اور تصدیق کر کے مقامی `foxchecker-singbox:latest` امیج بناتا ہے۔ جانچ کا اسکرپٹ اوپر لنک کیا گیا Docker Hub امیج استعمال کرتا ہے۔ GeoIP ڈیٹا کے ماخذ کے لیے [geoip/NOTICE](../geoip/NOTICE) دیکھیں۔
